
## 🔍 Exploratory Data Analysis (EDA)

### 📌 Objective

The objective of this task is to explore and understand the dataset before performing further analysis or building a model. EDA helps identify patterns, trends, relationships, and potential problems in the data.

### ❓ Questions Asked Before Analysis

* What are the main variables in the dataset?
* What is the distribution of the important variables?
* Are there any missing or duplicate values?
* Which factors are related to the target variable?
* Are there any unusual values or outliers?
* What patterns or trends can be observed from the data?

### Data Exploration

The dataset was explored to understand:

* Number of rows and columns
* Column names
* Data types of variables
* Missing values
* Duplicate records
* Statistical summary of numerical variables
* Unique values in categorical variables

### 📊 Data Analysis

Different statistical methods and visualizations were used to identify:

* Trends and patterns
* Relationships between variables
* Distribution of data
* Outliers and anomalies
* Differences between categories

###  Visualizations

The following visualizations can be used during EDA:

* Histograms
* Bar charts
* Box plots
* Scatter plots
* Count plots
* Correlation heatmaps

These visualizations make it easier to understand the dataset and identify meaningful relationships.

### Hypothesis Testing

Statistical analysis was used to test assumptions and validate observations found during the exploratory analysis.

For example, relationships between important variables can be examined using statistical measures such as correlation and appropriate hypothesis tests.

### Data Issues Identified

During the EDA process, potential issues such as:

* Missing values
* Duplicate records
* Outliers
* Incorrect data types
* Inconsistent values

were identified for further preprocessing and analysis.

### Outcome

The EDA process provided a better understanding of the dataset and helped identify important patterns, relationships, and data-quality issues that should be addressed before further analysis or machine learning.
